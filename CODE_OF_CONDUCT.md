# Code of Conduct

This project aims to keep technical discussion useful, respectful and welcoming.

Contributors and maintainers are expected to:

- discuss code and behavior without personal attacks
- give review feedback that is specific and actionable
- respect different experience levels, platforms and communication styles
- avoid harassment, discrimination, threats and deliberately disruptive behavior
- keep security-sensitive information private until coordinated disclosure

Disagreement about API design, compatibility or implementation is normal. Argue
from reproducible behavior, tests and maintenance cost rather than from the
person making the proposal.

Maintainers may edit, hide or remove abusive content and may restrict
participation when someone repeatedly ignores these expectations.
